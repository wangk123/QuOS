# ADR-003: v1 整体废弃,旧数据不迁移

日期:2026-10-14 · 状态:已接受

## 决策

v1 代码(server/app 的 LLM 编排、功能树/证据池/规则库/画像存储、对应前端)整体废弃重做;现有三个项目的已生成数据(规则库、画像、基线)不迁移。仅原始材料文件保留,作为新链路的验收用例(从材料重新整理)。

## 理由

1. v1 的核心资产是**材料与人脑中的意图**,不是生成的中间产物——规则库/画像可由 agent 在新链路上重新整理,且质量预期更高(消歧闭环+整文自查是新链路自带能力);
2. 旧数据结构与 v2 概念模型(章节式文档/题目/草案/版本)不兼容,迁移成本高于重跑;
3. 用「多模态」项目的真实材料重跑一遍,天然充当新链路的端到端验收。

## 后果

- v1 代码在 v2 分支上删除,git 历史保留可考古;
- 验收标准:多模态材料 → 新链路 → 定稿 v1 文档,人全程只在闸门出现。
