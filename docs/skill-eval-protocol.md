# Skill 评测协议(评分机制 · rubric · 优化验证闭环)

> 产生背景:2026-10-16 需求文档生成 skill 对比实验(本地 req-organize vs 4 个社区 PRD skill,同一份瀚海多模态素材)。本文件固化该实验的评分机制与后续「改 skill → 重生成 → 重评 → 对比」验证流程,skill 每次优化后按此协议复评。
> 实验数据存档:`/tmp/prd-compare/`(素材 material-multimodal.md、产物 out/、匿名件 blind/);临时目录,重要结论回填本文。

## 1. 评分机制(已验证有效,沿用)

- **评审独立性(强制)**:评审子代理与生成子代理**不得读取项目文档(AGENTS.md/项目内其他 skill)与任何全局记忆**——生成侧只读被测 SKILL.md+素材,评审侧只读素材+待评文档+rubric;避免项目习惯与先验污染双向结果。
- **盲评**:产物匿名化(doc-a/b/c/…),剥离执行记录与署名,评审不知道文档来自哪个 skill/作者。
- **独立多评审**:至少 1 个独立评审子代理,重要结论用 2 个交叉(已验证两评审排名一致、分差 <50,尺子稳定)。
- **事实基准唯一**:评审只依据「素材原文 + 待评文档」,不引入先验。
- **五维各 200 分,总分 1000**:功能完整性 / 清晰明了 / 事实真实性 / 可阅读性 / 必备要素。
- **捏造界定**(2026-10-16 实验确认有效):素材中不存在、且不属于「为行文通顺/结构完整做的合理组织性文字」的信息(凭空的阈值/端口/日期/数据/用户决策/统计结论)才计捏造;**归纳、分组命名、格式化、细节补充完善不算**;拿不准标"存疑"单独列出,不作重扣。
- **评审要求**:先从素材独立梳理能力域与行为点清单再逐份对照;抽查点带行号证据;分数拉开差距;排名+总结论(哪份最值得作团队底稿,为什么)。

## 2. rubric v1 的两个判定缺陷(2026-10-16 实验暴露)

1. **完整性抽查点全是后端视角**(阈值/错误码/状态机),没有交互面检查——导致丢失页面/操作入口/用户反馈的文档未被扣够分。
2. **可读性奖励了清单化**:「编号体系+交叉引用严密」「固定结构扫读一致」被评为清晰加分,实际是规则清单堆砌的模板感;叙事质量与读者体验未进判据。

## 3. rubric v2(2026-10-16 修订,下次评审启用)

### 3.1 功能完整性(v2)
抽查集必须覆盖四类,缺一类即完整性封顶 150:
- 后端行为(阈值/状态/异常语义)
- 参数与契约(接口/错误码/枚举值)
- **交互面:页面与操作入口(用户在哪操作)、关键操作流、系统反馈与提示(操作结果用户看到什么)、新用户上手路径**
- **用户与场景:每用户类端到端场景含异常分支,场景是否写穿交互层**

### 3.2 可阅读性(v2)
- 目标读者(业务/开发/测试)10 秒定位:目录与导航能否直达自己关心的部分
- 扫读快车道:关键信息由结构块(表/图/状态链/异常块)承载,还是埋在长段落里
- **清单化惩罚:连续超 10 条同构条目无分组叙事 → 每处扣 20-30;编号规则/故事列表作为文档主要内容形态 → 扣 40 起**
- 叙事质量:章首是否一段自然话讲清本章故事(服务谁、讲什么);读者能否拿着文档向他人复述系统怎么用
- (v1 的「编号交叉引用」「固定结构一致性」不再作为加分项)

### 3.3 其余三维(微调)
- 清晰明了:歧义/名实混用照旧;编号体系本身不加分。
- 事实真实性:同 v1 捏造界定;另查「评审性结论混入」(文档自评 Go/Fit/评分等替团队做的决策)。
- 必备要素:背景动机/目标与成功标准/用户与场景(含交互)/功能/边界与异常/非功能/开放问题/范围;交互设计考量(上手难度/操作负担)并入「用户与场景」要素检查。

## 4. 优化验证闭环(skill 每次优化后执行)

```
改 skill(记录改动点清单)
  → 同一素材派新生成子代理(约束与上轮完全一致:材料替代访谈/未决不编造/忠实执行 skill)
  → 产物匿名化(doc-<next>),连同上轮产物与对照文档一起
  → 派新评审子代理按 rubric v2 盲评(全部文档同批重评,保证同尺可比)
  → 对比:总分与五维变化、上轮短板是否修复、rubric 变化对旧文档分数的影响(归因校准)
  → 结论回填本文件附录,skill 改动点是否生效以分数与评审证据为准
```

校准规则:重评时旧文档分数会因 rubric v2 变化而移动,这是预期;归因方法是看**相对排名与短板项的针对性变化**,不是绝对分差。
