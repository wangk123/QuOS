# M1 reqspec 模块实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现需求整理模块的可用 MVP：碎片材料入池 → AI 提断言/核验 → 冲突/空白 → 卡片组装 → 问人清单 → 基线存档与增量定位，前后端完整闭环。

**Architecture:** FastAPI 后端（文件系统 + git 为源，无数据库）+ Vue3 前端（两级导航：项目层/整理层）。AI 编排器直连 OpenAI 兼容 API（httpx，无 SDK 无框架），每个任务 = prompts/ 下的模板 + pydantic 输出校验 + 闸门。

**Tech Stack:** Python 3.12+ / uv / FastAPI / httpx / pytest；Vue 3 + Vite + TS + vitest；git CLI（subprocess）。

**Spec:** `docs/specs/2026-09-23-reqspec-design.md`（本计划从 spec 出发，执行者需同时阅读 spec 与本计划）

## Global Constraints

- Python 一律 `uv run`；依赖仅：fastapi、uvicorn、httpx、pydantic、pytest、pytest-asyncio（前端：vue、vite、typescript、vitest）——不新增其他依赖
- 文件为源：无数据库；`data/<项目>/` 下 md + json；平台只做编排与视图
- commit 格式：`<type>：<描述>`（中文描述，type 用 feat/test/fix/refactor/chore）
- 单文件行数上限：模块 500 行、工具 300 行；超限按职责拆
- LLM 配置从环境变量读：`QUOS_LLM_BASE_URL`、`QUOS_LLM_API_KEY`、`QUOS_LLM_MODEL`；测试一律 mock，不发真实请求
- prompt 模板全部落 `server/app/ai/prompts/*.md`，git 版本化——prompt 即代码，改动走 commit
- 交互与视觉以 `prototype/reqspec.html` 为基准

## Review Focus

1. **AI 返回非法 JSON 或不符 schema** → 重试 1 次后抛 `AITaskError`，绝不静默产出半成品断言（Task 6 测试）
2. **tree.md 被手工改坏（缩进跳跃/非列表行）** → 解析抛 `TreeFormatError` 带行号，API 返回 422 而非 500（Task 4 测试）
3. **「AI 待实证」断言混入组装** → assemble 前校验，发现未实证/未核验断言则拒绝组装并返回清单（spec §① 硬阻断）（Task 9 测试）
4. **节点名含 `/` `\` 空格等文件系统字符** → 卡片文件名 slug 化，重名自动加后缀（Task 5 测试）
5. **证据索引指向的文件被外部删除** → 列表标记 `missing: true` 并降星提示，不抛异常（Task 3 测试）

```python
# server/app/core/classify.py
import re

_REPO = re.compile(r"^(git@|https?://\S*(?:github|gitlab|gitee|git))", re.I)
_BRANCH = re.compile(r"^(.+?\.git)[@\s]+([\w][\w/\-.]*)$", re.S)

def classify_text(v: str) -> dict:
    v = v.strip()
    if _REPO.match(v):
        m = _BRANCH.match(v)
        if m:
            return {"type": "仓库", "name": m.group(1), "ext": "@" + m.group(2), "stars": 3}
        return {"type": "仓库", "name": v, "ext": "", "stars": 3}
    is_url = v.startswith("http://") or v.startswith("https://")
    return {"type": "文本", "name": v[:38] + ("…" if len(v) > 38 else ""),
            "ext": "文本·链接" if is_url else "文本·粘贴", "stars": 2}

def classify_file(filename: str) -> str:
    ext = filename.rsplit(".", 1)[-1].lower() if "." in filename else ""
    if ext in {"zip", "rar", "7z", "tar", "gz"}:
        return "压缩包"
    if ext in {"png", "jpg", "jpeg", "gif", "webp"}:
        return "截图"
    return "文档"
```

```python
# server/app/storage/evidence.py 核心
import json, uuid
from pathlib import Path
from datetime import date
from app.core.models import Evidence

def _idx(root: Path) -> Path: return root / "evidence" / "index.json"

def _load(root) -> list[dict]:
    p = _idx(root)
    return json.loads(p.read_text("utf-8")) if p.exists() else []

def _save(root, rows): 
    _idx(root).parent.mkdir(parents=True, exist_ok=True)
    _idx(root).write_text(json.dumps(rows, ensure_ascii=False, indent=1), "utf-8")

async def add(root, payload: dict, content: bytes | None = None) -> Evidence:
    rows = _load(root)
    row = {"id": payload.get("type", "文本")[:4].upper() + uuid.uuid4().hex[:4],
           "reg": date.today().isoformat(), "path": None, **payload}
    if content is not None:
        fdir = root / "evidence" / "files"; fdir.mkdir(parents=True, exist_ok=True)
        f = fdir / payload["name"]; f.write_bytes(content); row["path"] = str(f.relative_to(root))
    rows.append(row); _save(root, rows)
    return Evidence(**row)

async def list_all(root) -> list[Evidence]:
    out = []
    for r in _load(root):
        if r.get("path"):
            r["missing"] = not (root / r["path"]).exists()
            if r["missing"]: r["stars"] = max(0, r.get("stars", 2) - 1)
        out.append(Evidence(**r))
    return out
```

- [ ] **Step 2: 确认失败** → **Step 3: 实现**（逐行解析：只认 `- ` 开头行，`indent = (len(line) - len(line.lstrip()))` 必须为偶数且 ≤ 上层 indent+2，否则抛 `TreeFormatError(line_no)`；dump 递归 2 空格缩进）

```python
# server/app/storage/tree.py 核心
class TreeFormatError(Exception):
    def __init__(self, line): super().__init__(f"tree.md 第 {line} 行缩进非法")

def parse(md_text: str) -> list[Node]:
    stack: list[tuple[int, Node]] = []  # (indent, node)
    roots: list[Node] = []
    for no, raw in enumerate(md_text.splitlines(), 1):
        if not raw.strip() or not raw.lstrip().startswith("- "):
            continue
        indent = len(raw) - len(raw.lstrip("- "))
        if indent % 2 or (stack and indent > stack[-1][0] + 2) or (not stack and indent > 0):
            raise TreeFormatError(no)
        node = Node(name=raw.lstrip()[2:].strip())
        while stack and stack[-1][0] >= indent:
            stack.pop()
        if not stack: roots.append(node)
        else: stack[-1][1].children.append(node)
        stack.append((indent, node))
    return roots
```
