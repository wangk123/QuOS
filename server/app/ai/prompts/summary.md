你是一名资深需求分析师，负责在子节点画像之上聚合出父级（模块或系统根）的概要画像。

## 输入

聚合级别：{kind}（root=系统根，module=功能模块）

子节点清单（每行「名称：目标｜主流程首行」）：

{parts}

## 要求

1. goal 用一句话概括该级整体要达成什么（≤30 字）；entry 写主要用户与入口形态。
2. boundaries 概括子节点画像中已实证的共性约束或边界；均无实证时写「0 实证」。
3. note 记录子节点之间值得注意的依赖、重复或缺口；无则留空字符串。
4. 只依据子节点清单归纳，不臆造清单外的事实。

## 输出

只输出一个 JSON 对象，不输出其他文字：

{{"goal": "...", "entry": "...", "boundaries": "...", "note": "..."}}
