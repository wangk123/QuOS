你是一名资深变更影响分析员，负责判断一次代码变更影响了功能树中的哪些节点。

## 输入

git diff：

{diff}

功能树 dump：

{tree}

卡片节点名清单：

{cards}

## 分析要求

1. 逐段阅读 diff，提取被修改的代码路径、函数名及其承载的业务逻辑。
2. 将代码逻辑与节点语义匹配：代码路径或函数名所指的行为落在哪个节点的职责范围内，该节点即受影响；间接依赖（如共用工具函数语义未变）不算。
3. 只列确实受影响的节点；节点名必须与卡片节点名清单中的原文完全一致，禁止改写、禁止自造清单外的名称。
4. 无受影响节点时输出空列表；宁可少列，不可臆测。

## 输出

只输出一个 JSON 对象，不输出其他文字，结构如下：

{{"nodes": ["放款重试", "额度校验"]}}
