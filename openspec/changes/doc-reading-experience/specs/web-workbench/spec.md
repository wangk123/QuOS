# web-workbench Delta

## MODIFIED Requirements

### Requirement: 文档评审页布局
文档评审页 SHALL 为固定视口结构(各栏独立滚动,页面不整体滚动):文档区 = 文档头(版本信息+可选一句话概要与关键词 chips+读者路径行+统计 chips:章节数/active 规则数/待答批注数/术语数,统计由前端从数据派生;新字段缺省时对应区块不渲染) + 文档正文(章节层级编号渲染,正文块按 para/states/table/figure/exceptions/diagram/cards 分派,规则编号锚点,恒全宽;每章渲染章级主题色与编号徽章,章内强调、速览、徽章取章色;章末渲染本章规则速览 chips 可点击定位;para 与规则 text 的 `**强调**` 渲染为章色强调) + 「待确认问题」汇总区(位于术语表章前,数据为 pending 的 agent 批注只读聚合:题型徽章+题面摘要+规则引用 chip,点击激活右栏对应批注卡;pending 清零则不渲染) + 内嵌目录列(章节树:层级编号+每章批注计数,滚动联动高亮当前章;三态 pinned/hover/hidden;右缘拖拽调宽限界并记忆);术语表以文档末章词条表呈现;右 = 批注栏。工具条含:草案状态徽标、基于基线版本与摘要文字、定稿发版按钮。

#### Scenario: 独立滚动
- **WHEN** 用户滚动文档正文
- **THEN** 仅文档区滚动,批注栏位置不动

#### Scenario: 目录宽度拖拽
- **WHEN** 用户拖动目录右缘把手调整宽度
- **THEN** 目录宽度在限界内变化并记忆,刷新后保持;正文流式区域相应伸缩

#### Scenario: 旧数据降级渲染
- **WHEN** 打开无 summary/keywords/reader_paths/cards 的新标记的既有草案
- **THEN** 文档头仅渲染版本信息与统计,无概要区;正文无强调但不出现 `**` 星号;其余布局不变

#### Scenario: 章末速览定位
- **WHEN** 用户点击第 5 章速览条上的 FR-203 chip
- **THEN** 文档区滚动至该章 FR-203 规则行并短暂高亮

#### Scenario: 待确认汇总区随清零消失
- **WHEN** 最后一条 pending 批注被裁决
- **THEN** 「待确认问题」汇总区不再渲染,文档直接衔接术语表章

### Requirement: 正文批注与规则锚点
文档正文 SHALL 支持批注高亮标记(未答琥珀、已答绿)与规则编号锚点:点正文标记激活右栏对应批注卡;点规则编号弹出 popover(怎样算违反/出处引用/材料 hash)。批注 seg 锚定与术语出现章搜索 SHALL 在剥离 `**` 强调标记后的纯文本上执行,渲染层同时呈现强调与批注高亮。

#### Scenario: 点规则编号
- **WHEN** 用户点击规则编号 R13
- **THEN** 弹出 popover 展示可判定表述与出处引用,点击外部关闭

#### Scenario: 带标记文本锚定命中
- **WHEN** 规则 text 为「短信验证码为 **6 位数字**」,存在 seg=「6 位数字」的 pending 批注
- **THEN** 剥离标记后命中,渲染结果中「6 位数字」同时带章色强调与琥珀批注标记
