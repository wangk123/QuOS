# review-gate 能力 delta

## ADDED Requirements

### Requirement: 批注锚定正文
平台 SHALL 在草案成文时将全部待确认问题以**批注**形式锚定在文档正文上:规则句级批注(边界未定义/材料冲突/可判定存疑/实证核对)、术语批注(锚在术语首次出现处)、章节级批注(空壳章节:无正文块且零规则,锚在章节标题旁)。批注是题目的呈现形态,题型仍限四种:choice / confirm / fill / scan。
#### Scenario: 边界问题锚定规则句
- **WHEN** 草案中 R12 的「30 分钟未支付」边界未定义
- **THEN** 正文 R12 规则句中该片段呈批注高亮并带编号角标,右栏出现对应批注卡

### Requirement: 右栏批注列表与折叠
平台 SHALL 在文档评审页右侧呈现批注栏:按章节分组分块;批注卡**默认折叠**(只显示问题摘要一行 + 编号·类型小字元信息行),点击卡片头展开查看上下文与作答选项;每张未答批注卡带「定位到正文」按钮(滚动正文至锚点并高亮);作答完成后卡片自动收起转绿、正文对应标记同步转绿;已答批注可「重新作答」。
#### Scenario: 折叠与展开
- **WHEN** 评审页加载,存在 9 条批注
- **THEN** 右栏 9 条批注卡全部折叠,一屏可见全部摘要;点某卡展开显示上下文与选项,再点收起
#### Scenario: 定位正文
- **WHEN** 用户点击批注卡的定位按钮
- **THEN** 文档区滚动到正文锚点并高亮闪烁,该批注卡展开并置为激活态

### Requirement: 两种评审模式
平台 SHALL 支持对照与逐条两种模式:对照 = 章节树 / 文档正文 / 批注栏三栏同屏(各自独立滚动);逐条 = 单卡聚焦 + 进度 + 上/下一条推进 + 正文自动定位。
#### Scenario: 逐条推进
- **WHEN** 用户切换逐条模式并点击「下一条」
- **THEN** 焦点批注卡切换,正文自动滚动定位到新批注锚点

### Requirement: 答案供 agent 取回
平台 SHALL 提供 GET /api/v1/projects/{pid}/questions?status=answered 返回已答批注(题型、题干、答案、锚点、作答时间),支撑 agent 下次唤起时继续收敛。
#### Scenario: agent 取答案续跑
- **WHEN** agent 再次被唤起,拉取 answered 批注
- **THEN** 获得全部已答明细(含锚点位置),据答案更新草案并重新提交
